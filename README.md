# Immersive Helper

Immersive Helper — мод для Fabric, закладывающий техническую основу интерактивного NPC-помощника Guide. Проект находится на ранней стадии разработки: сейчас важны чистая архитектура, корректная регистрация сущности и готовность к дальнейшему расширению.

## Текущий статус

Уже реализованы:

- регистрация сущности `immersive_helper:guide`;
- базовые атрибуты здоровья и скорости;
- раздельные общая и клиентская точки входа;
- клиентская регистрация GeckoLib renderer и модели;
- русская и английская локализации.

Пока не реализованы:

- игровая логика помощника и сложный AI;
- естественный спавн и предмет призыва;
- GUI, команды, сеть и система владельца;
- полноценные анимационные контроллеры.

> [!WARNING]
> В репозитории пока отсутствуют `geo/guide.geo.json`, `textures/entity/guide.png` и `animations/guide.animation.json`. Dedicated server не загружает renderer, однако клиент не сможет корректно отрисовать Guide до добавления этих ресурсов. Сущность не имеет естественного спавна, поэтому в обычной игре это ограничение пока не проявляется само по себе.

Старая иконка содержала legacy-название проекта и была удалена. Новая иконка пока не подготовлена, поэтому поле `icon` в `fabric.mod.json` не задано.

## Требования

- Minecraft 26.2;
- Fabric Loader 0.19.3 или новее в совместимой ветке;
- Fabric API 0.155.2+26.2 или новее для Minecraft 26.2;
- GeckoLib 5.5.3 или новее для Minecraft 26.2;
- Java 25.

## Сборка

Перед сборкой установите JDK 25 и убедитесь, что он доступен системе. Проект использует Gradle Wrapper и Java Toolchain, абсолютные пути к JDK в конфигурации не задаются.

Windows:

```powershell
.\gradlew.bat clean build
```

Linux/macOS:

```bash
./gradlew clean build
```

Основной пользовательский файл создаётся по пути:

```text
output/immersive-helper-0.1.0+26.2.jar
```

Рядом может создаваться отдельный sources JAR. Каталог `output/` игнорируется Git.

## Структура проекта

```text
src/main/java/dev/sp1ley/immersivehelper/          общая логика и регистрация
src/client/java/dev/sp1ley/immersivehelper/client/ клиентская инициализация и renderer
src/main/resources/assets/immersive_helper/        локализации и будущие GeckoLib-ресурсы
src/main/resources/fabric.mod.json                  метаданные Fabric
```

## Планы развития

Логичные следующие этапы — подготовить модель, текстуру и анимации Guide, добавить безопасный способ создания сущности в тестовой среде, затем постепенно развивать поведение помощника. Конкретные сроки не заявлены.

## Ветки

- `1.21/dev` хранит исходную legacy-версию проекта для Minecraft 1.21.11.
- `26.2/dev` используется для разработки под Minecraft 26.2.
