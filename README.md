# Immersive Helper 0.2.0

Immersive Helper — ранний игровой прототип компаньона Алисы для одиночной игры Minecraft 26.2 на Fabric. Алиса следует за владельцем, помогает в ближнем бою и собирает выпавшие ресурсы во внутреннюю сумку.

## Требования

- Minecraft 26.2;
- Fabric Loader 0.19.3 или новее в совместимой ветке;
- Fabric API 0.155.2+26.2 или совместимая версия;
- GeckoLib 5.5.3 или совместимая версия;
- Java 25.

## Установка

Соберите проект или скачайте основной пользовательский JAR:

```text
output/immersive-helper-0.2.0+26.2.jar
```

Поместите основной JAR, Fabric API и GeckoLib в каталог `mods`. Файл с суффиксом `-sources.jar` содержит исходники и не устанавливается в `mods`.

## Команды

Команды доступны обычному игроку и не требуют ручной выдачи операторских прав:

```mcfunction
/alice summon
/alice collect
/alice status
/alice dismiss
```

- `/alice summon` призывает одну Алису в безопасном месте рядом с игроком и назначает его владельцем.
- `/alice collect` переносит содержимое сумки в инвентарь владельца, сохраняя непоместившийся остаток.
- `/alice status` показывает режим, здоровье и заполнение сумки.
- `/alice dismiss` убирает Алису; предметы сначала передаются владельцу, а остаток выбрасывается рядом без удаления.

ПКМ владельца по Алисе переключает режимы `FOLLOW` и `STAY`. В `STAY` Алиса остаётся на месте, не телепортируется и может защищаться от непосредственного нападения.

## Возможности прототипа

- следование за владельцем с pathfinding на дистанции примерно 3–5 блоков;
- безопасная телепортация рядом с владельцем при сильном отставании;
- отсутствие физического толкания владельца без отключения общей физики сущности;
- помощь в ближнем бою против враждебных существ, связанных с недавним боем владельца, и самозащита;
- ограниченный поиск выпавших предметов в радиусе 6 блоков через интервалы;
- внутренняя сумка на 18 слотов с объединением совместимых стаков;
- передача ресурсов владельцу без удаления непоместившихся остатков;
- выдача одной ранее подобранной обычной еды при здоровье владельца не выше трёх сердец;
- сохранение UUID владельца, режима, приветствия и содержимого сумки вместе с сущностью;
- оригинальная GeckoLib-модель, пиксельная UV-текстура и анимации ожидания, ходьбы и атаки;
- редкие локализованные сообщения только о важных действиях.

При смерти Алисы содержимое сумки один раз выбрасывается обычными предметами в месте смерти, после чего сумка очищается. Владельцу отправляется сообщение, а новую Алису можно призвать командой. При `/alice dismiss` предметы не теряются: они передаются в инвентарь или остаются рядом с владельцем.

## Ограничения

- это ранний прототип только для Minecraft 26.2 Fabric;
- проект пока ориентирован на одиночную игру;
- GUI сумки отсутствует;
- сложных диалогов, уровней и навыков нет;
- поддерживается только одна активная Алиса на владельца;
- Алиса не создаёт ресурсы или еду из воздуха и не заставляет игрока автоматически есть;
- игровые сценарии требуют ручной проверки в обычном клиенте Minecraft.

## Сборка

Windows:

```powershell
.\gradlew.bat clean build
```

Linux/macOS:

```bash
./gradlew clean build
```

Проект использует Gradle Wrapper 9.6.1, Kotlin DSL и Java Toolchain 25. Основной JAR создаётся в `output/`.

## Ветки

- `1.21/dev` хранит legacy-версию для Minecraft 1.21.11.
- `26.2/dev` используется для разработки под Minecraft 26.2.
