# Журнал изменений

Все заметные изменения проекта документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), а версии следуют [Semantic Versioning](https://semver.org/lang/ru/).

## [0.2.0] - 2026-07-25

### Добавлено

- Команды `/alice summon`, `/alice dismiss`, `/alice status` и `/alice collect`.
- Сохранение владельца, режима FOLLOW/STAY, приветствия и сумки на 18 слотов.
- Следование с pathfinding, безопасная телепортация при отставании и переключение режима по ПКМ.
- Базовая помощь в ближнем бою и самозащита.
- Интервальный подбор выпавших предметов с сохранением компонентов стаков.
- Передача собранных предметов и выдача ранее подобранной обычной еды при критическом здоровье.
- Безопасный возврат или выбрасывание содержимого сумки при dismiss и смерти.
- Оригинальные модель, UV-текстура, иконка и анимации ожидания, ходьбы и атаки.
- Русская и английская локализации всех пользовательских сообщений.
- Автоматическое извлечение каменного меча в бою.
- Визуальное отображение меча в правой руке и его скрытие после завершения боя.

### Изменено

- Версия мода обновлена до 0.2.0.
- Guide оформлена как игровой компаньон Алиса и больше не толкает владельца.
- Модель и анимации перенесены в каталоги ресурсов GeckoLib 5.
- Метаданные Mod Menu получили официальные русскую и английскую локализации.
- В список авторов добавлен sp1ley.
- Java namespace очищен от личного имени: исходники перенесены в `org.immersivehelper`.

### Исправлено

- Исправлена загрузка GeckoLib model/animation resources и вызванный отсутствующей animation timeline клиентский краш при призыве Алисы.
- GitHub Actions загружает основной JAR по шаблону версии и исключает sources JAR.
- `SavedData`-реестр предотвращает создание второй Алисы, когда первая находится в выгруженном чанке.
- Проверка заполненности сумки учитывает возможность дополнить совместимые стаки.
- Еда, выброшенная Алисой владельцу, больше не выбирается ею для повторного подбора.
- Алиса немедленно выбирает напавшего на неё противника и вступает в ближний бой.
- Выдача безопасной еды срабатывает не только при критическом здоровье, но и при уровне голода не выше двух единиц.
- Текстура Алисы переработана в корректный пиксельный UV-атлас по образу путешественницы.
- Устранено переключение на запрещённую боевую цель через `HurtByTargetGoal`.
- Проверка защиты владельца выполняется раз в 5 тиков вместо каждого тика.
- В режиме STAY преследование ограничено радиусом 10 блоков, после боя Алиса возвращается к точке ожидания.
- Визуальный меч не создаёт второй источник урона, не попадает в сумку и не выпадает.
- Исправлен чёрный экран при запуске, вызванный слишком ранним созданием `ItemStack` каменного меча до привязки Data Components.

## [0.1.0] - 2026-07-25

### Добавлено

- Основа сущности Guide, её базовых атрибутов и клиентского GeckoLib renderer.
- README на русском языке.
- `.editorconfig`, `.gitattributes` и расширенный `.gitignore`.
- GitHub Actions workflow для проверки Wrapper и сборки на Java 25.

### Изменено

- Основа проекта перенесена из ветки `1.21/dev`.
- Целевая версия обновлена с Minecraft 1.21.11 до 26.2.
- Java обновлена с 21 до 25.
- Gradle Wrapper обновлён до 9.6.1.
- Сборка переведена с Groovy DSL на Gradle Kotlin DSL.
- Fabric Loader, Fabric API, Fabric Loom и GeckoLib обновлены до совместимых версий.
- Проект переведён на unobfuscated Minecraft API без Yarn mappings.
- Название нормализовано до `Immersive Helper`, артефакт — до `immersive-helper`.
- Legacy Mod ID заменён на `immersive_helper`.
- Entity ID изменён на `immersive_helper:guide`.
- Java package сначала использовал личный namespace (в 0.2.0 он окончательно нормализован до `org.immersivehelper`).
- Общий и клиентский код разделены по source sets.
- Пути будущих GeckoLib-ресурсов приведены к единой структуре.

### Удалено

- Groovy-файлы `build.gradle` и `settings.gradle`.
- Yarn-конфигурация для Minecraft 1.21.11.
- Пустой и неиспользуемый класс регистрации предметов.
- Legacy-иконка со старым названием проекта.
- Старые package-пути, идентификаторы и метаданные версии.
- Генерируемые каталоги, IDE-файлы и runtime-артефакты из отслеживаемой структуры.

### Исправлено

- Регистрация сущности, атрибутов и renderer адаптирована к API Minecraft 26.2.
- Метаданные, локализации и зависимости приведены к единому Mod ID.
